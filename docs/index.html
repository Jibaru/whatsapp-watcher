WhatsApp Watcher

Un notetaker de WhatsApp sobre AWS. Mandas un mensaje —texto, foto o nota de voz—, un modelo lo entiende y lo guarda estructurado. Anotar no responde nada: lo que escribiste vuelve como recordatorio a la hora que pediste, y una vez al día por correo.

Usuario→ KAPSO→ API Gateway→ ingest→ DynamoDB→ outbox→ EventBridge→ SQS→ processor→ OpenAI
